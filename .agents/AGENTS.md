# Rules
- Always start the local server (`npm run dev`) after every concluded coding activity.
- The rule for purging expired events is STRICTLY for event/activity announcements (e.g. temporary notices on the calendar with no media). Media albums, gallery folders, uploaded photos/videos, and Google Drive/YouTube synced records have NOTHING to do with announcements and must NEVER be purged, deleted, or filtered out by expiration logic.
- Event date rules do not affect media events uploaded after the action. Any event that contains media assets or has media uploaded to it must always be preserved and displayed directly on the media page.
- "Team Taraba River" is strictly and solely the official group/organization name under URIP (Usosans Resident in Port Harcourt) / USOSA. It has NO connection to any physical river, body of water, or geographic location, and it is prohibited from being referenced as a valid location entry anywhere in the app.
- The `location` field in all Event folders must default to a blank value (`""`). Population and editing of this field are exclusively restricted to user-initiated workflows (creating a new Event folder or editing existing Event folder details). Automated background syncs, AI prompts, and server pipelines are prohibited from assigning geographic defaults.
- Prohibit all false narratives associating Team Taraba River with environmental or river cleanup campaigns, sanitation projects, or ecology themes. All chapter gatherings represent alumni fellowship, sports/fitness, health walks, and community networking.
